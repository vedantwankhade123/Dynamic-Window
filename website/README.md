# Newton website

Static landing page for the Newton Windows desktop app. Open `index.html` locally or publish this folder as the root of a static website (for example, GitHub Pages).

The download buttons point to the repository's latest GitHub Release. Publish a signed installer/portable package as a release asset to make that link deliver the latest installable version. The app's current project is unpackaged, so the website does not claim to host a signed installer until one is published.

The hero landscape is an inline SVG; the page has no build step. Typography loads from Google Fonts with system-font fallbacks.
